Detailed Description

Класс для описания 3D объекта.

Класс предоставляет функциональность для парсинга данных 3D объекта из файла, управления его вершинами и гранями, а также методы для чтения данных о вершинах и гранях.

◆ Parse()

bool s21::Object::Parse ( std::string path)

Открывает файл по указанному пути и считывает содержимое построчно.

Обрабатывает строки, начинающиеся с "v " для чтения вершин и "f " для чтения граней. Если файл не удается открыть, выбрасывается исключение с соответствующим сообщением об ошибке.

Parameters
pathПуть к файлу.
Returns
true если парсинг выполнен успешно, иначе false.

◆ ReadFacet()

bool s21::Object::ReadFacet ( std::string & str)

Читает данные о грани из строки и добавляет её в список граней.

Если индекс превышает количество вершин или является недопустимым, выбрасывается исключение. Если индекс отрицательный, он преобразуется в положительный, основываясь на количестве вершин в объекте. После успешного считывания, грань добавляется в вектор граней, а счетчик рёбер увеличивается.

Parameters
strСсылка на строку, содержащую данные о грани, начинающиеся с "f ".
Returns
true если чтение грани прошло успешно, иначе false.

< один полигон

< номер вершины

< номер вершины, записанный в строку

Читает координаты вершины из строки и добавляет её в список вершин.

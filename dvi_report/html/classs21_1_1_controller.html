Detailed Description

Класс Controller для управления объектами типа Object.

Предоставляет интерфейс для взаимодействия с объектами типа Object. Позволяет открывать файлы, получать информацию о вершинах и гранях, а также выполнять операции перемещения и вращения объекта в трехмерном пространстве.

◆ Zoom()

void s21::Controller::Zoom ( double value)

Метод для изменения масштаба объекта.

Принимает значение масштаба и применяет его к объекту, создавая новый объект типа ZoomObject, который будет использоваться для изменения масштаба.

Parameters
valueЗначение масштаба, которое будет применено к объекту по всем осям (X, Y, Z).

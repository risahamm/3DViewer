Detailed Description

Базовый класс для преобразований объектов.

Служит абстрактным базовым классом для всех классов, реализующих преобразования объектов, такие как вращение (rotate), перемещение (move) и масштабирование (zoom). Определяет интерфейс для модификации объекта через виртуальный метод Modify().

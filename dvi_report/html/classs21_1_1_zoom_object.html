Detailed Description

Класс ZoomObject для выполнения операций масштабирования.

Класс наследует от TransformationsBaseClass и предоставляет функциональность для изменения размера объекта. Принимает указатель на объект типа s21::Object в конструкторе.

Инициализирует объект ZoomObject, передавая указатель на объект в базовый класс TransformationsBaseClass. Это позволяет производить операции масштабирования на заданном объекте.

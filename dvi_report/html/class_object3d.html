Detailed Description

Класс для представления и отображения 3D объектов с использованием OpenGL.

Класс наследует от QOpenGLWidget и реализует функции OpenGL для инициализации, отрисовки и изменения размеров виджета. Предназначен для работы с 3D графикой и предоставляет методы для управления положением объектов по осям, а также настройки проекции и стилей отрисовки.

Отрисовка сцены.

Метод переопределяет виртуальный метод paintGL и вызывается каждый раз, когда требуется перерисовать виджет. Отвечает за отрисовку объектов на экране, включая настройку фона, очистку цветового буфера и рендеринг вершин и граней.

  1. Устанавливает цвет фона с помощью SetUpBackgroundColor().
  2. Очищает цветовой буфер с помощью glClear(GL_COLOR_BUFFER_BIT).
  3. Настраивает проекцию с помощью SetUpProjection().
  4. Получает вершины объектов через контроллер.
  5. Рисует грани, используя заданные цвет и стиль линии.
  6. Если задан стиль отрисовки вершин (точки или квадраты), устанавливает размер точек и рисует их.

Изменение размера виджета.

Метод переопределяет виртуальный метод resizeGL и вызывается при изменении размера виджета. Он обновляет параметры области просмотра OpenGL, устанавливая новые размеры для рендеринга. Принимает ширину и высоту нового размера виджета и вызывает функцию glViewport, чтобы настроить область просмотра на весь доступный размер виджета.
